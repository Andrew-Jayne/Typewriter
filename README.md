# TypeWriter

A simple, focused, and flexible tool for writing and reading with built-in markdown rendering, built as a static web app with vanilla HTML, CSS, and JavaScript. Offline-first and makes no network requests, download the single HTML file, open it in any web browser, and start writing. All data is stored on your device via localStorage.
